# 💎 Comex Metals Dashboard

CME Group Değerli Metaller Open Interest Dashboard - Gerçek zamanlı altın, gümüş, bakır, platinum ve palladyum fiyatlarını takip edin.

## 🌟 Özellikler

- 📈 **Gerçek Zamanlı Grafik** - Live fiyat güncellemeleri
- 📊 **Tarihsel Veriler** - Geçmiş fiyat trendleri
- 🔔 **Uyarı Sistemi** - Özel fiyat uyarıları ayarlayın
- 💾 **Veri Kaydı** - Geçmiş verileri saklayın
- 🌓 **Dark/Light Mode** - Tema seçeneği
- 🎨 **Modern UI** - Svelte + Tailwind CSS

## 🏆 Desteklenen Metaller

- 🥇 **Altın (Gold)** - COMEX GC
- 🥈 **Gümüş (Silver)** - COMEX SI
- 🧅 **Bakır (Copper)** - COMEX HG
- 🤍 **Platinum** - NYMEX PL
- 🤍 **Palladyum (Palladium)** - NYMEX PA

## 🚀 Başlangıç

### Gereksinimler
- Node.js 16+
- npm veya yarn

### Kurulum

```bash
# Repository'yi klonlayın
git clone https://github.com/edacoskuner-starMErhaba/comex_metals_dashboard.git
cd comex_metals_dashboard

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Tarayıcıda açın
# http://localhost:5173
